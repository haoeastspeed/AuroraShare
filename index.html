FAQ

常见问题

访问的电脑或手机需要安装软件吗？+
不需要。任意设备用浏览器输入服务端地址即可访问；若希望把共享映射成盘符，可使用系统自带的 WebDAV 功能；需要加密时，也可用任意支持 SFTP 的客户端连接。
数据会上传到云端吗？安全吗？+
不会。所有文件传输都在你自己的局域网内完成，不经过任何外部服务器。可设置访问口令，未授权无法访问；WebDAV 需鉴权，SFTP 基于 SSH 全程加密。
不在同一个局域网还能用吗？+
本软件定位局域网"即发即用"。若设备分布在不同网络，可配合 ZeroTier 等虚拟组网工具，让设备获得同一虚拟内网的 IP，之后照常使用。
和 Windows 自带的 SMB 网络共享有什么区别？+
SMB 需要配置账户、网络发现与权限，手机和平板往往无法直接访问。极光Share 免配置、扫码即达，任意带浏览器的设备都能用，也更适合临时、快速的分享场景。
支持哪些系统？+
共享服务端为 Windows 10 / 11（64 位）单文件；访问端不限系统，Windows、macOS、Android、iOS、鸿蒙等任意带浏览器的设备均可。
如何防止局域网里其他人随意打开？+
设置访问口令后，必须输入正确口令才能浏览、下载或上传；也可以把共享设为只读，避免他人改动文件。关闭服务后共享立即停止。
