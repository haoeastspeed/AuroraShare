# 极光Share AuroraShare

> 服务端一键启动，访问端（电脑 / 手机 / 平板）浏览器**零安装**的局域网文件共享工具。

## 特点

- **访问端零安装**：浏览器输入服务端 IP（或扫码）即可，全平台通用
- **三种共享模式**
  - 网页 HTTP：浏览、搜索、上传、下载、管理、ZIP 打包
  - WebDAV：可在文件管理器映射为网络盘
  - SFTP：强加密、单端口、断点续传
- **单文件 exe**：Rust 编写，无需运行环境，开箱即用
- **安全**：自定义访问口令，数据只在你的设备之间流转，不上传云端

## 使用方法

1. 在共享**服务端**电脑下载并运行「极光Share.exe」
2. 设置共享目录与访问口令，按需启动 HTTP / SFTP 服务
3. 在任一访问设备的浏览器打开界面显示的地址（或扫描二维码）
