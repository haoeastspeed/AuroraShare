# 极光Share AuroraShare

> 只在共享服务端启动一个软件，电脑 / 手机 / 平板用浏览器输入 IP 或扫码即可访问、上传、下载文件。**访问端零安装、免账号、数据不出局域网。**

## 特性

- **访问端零安装**：任意设备用浏览器访问，或手机扫码直达，系统不限。
- **三种共享方式**：网页 HTTP（功能最全）、WebDAV（映射盘符）、SFTP（强加密、断点续传）。
- **单文件绿色**：一个 exe 双击即用，不写注册表、不装系统服务，可放 U 盘。
- **好用的功能**：全局文件搜索、多选 ZIP 打包下载、上传 / 新建 / 重命名 / 删除。
- **安全可控**：自定义访问口令，只读 / 可写自由切换，关闭服务即停止共享。
- **自动更新**：启动自动检查，下载后校验 SHA-256，自动替换并重启。

## 快速开始

1. 在要共享文件的 Windows 电脑上双击运行，选择共享目录并设置口令。
2. 在 `HTTP` 或 `SFTP` 选项卡中一键启动服务。
3. 其他设备用浏览器输入屏幕上的地址（如 `http://192.168.1.20:端口`），或扫码访问。
